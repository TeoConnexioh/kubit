# 인공지능은 어떻게 배우는가

비전공자를 위한 인터랙티브 AI 강의 사이트. 시냅스 하나의 학습에서 시작해
트랜스포머와 LLM, 그리고 LLM의 추가 학습(미세조정·LoRA)까지, **직접 만져보며** 이해하도록 만든 단일 페이지 강의입니다.

## 실행 방법

빌드 도구나 설치 없이 순수 HTML/CSS/JS로 되어 있습니다. 로컬 서버로 열기만 하면 됩니다.

```bash
# 프로젝트 폴더에서
python3 -m http.server 8777
# 브라우저에서 http://127.0.0.1:8777 접속
```

> `index.html`을 파일로 직접 열어도 대부분 동작하지만, 일부 브라우저의 보안 정책 때문에
> 위처럼 로컬 서버로 여는 것을 권장합니다.

## 강의 구성

| # | 챕터 | 핵심 개념 | 인터랙티브 데모 |
|---|------|-----------|------------------|
| 01 | AI란 무엇인가 | 규칙을 사람이 짜는 대신 데이터에서 찾게 하기 · AI ⊃ ML ⊃ 딥러닝 ⊃ 트랜스포머 ⊃ LLM 포함 관계 | 집합 지도 (층 클릭) |
| 02 | 학습이란 무엇인가 | 시냅스 = 가중치를 조정하는 것 · 뉴런 하나의 한계(XOR)와 층 쌓기 | **뉴런 한 개의 학습** (퍼셉트론 AND/OR/XOR) · 신경망 신호 흐름 |
| 03 | 기계학습 | 오차가 줄어드는 방향으로 한 걸음씩 · 학습률과 과적합 | **경사하강 선형회귀** (직선 드래그·자동 학습) |
| 04 | 강화학습 | 보상을 좇는 시행착오 · 탐험과 활용 · 표 vs 신경망(암기 vs 일반화) | **그리드월드 Q-러닝** · **4-보너스: 같은 미로를 신경망으로** |
| 05 | 트랜스포머 | 단어들이 서로 주목(어텐션) · Q·K·V · 멀티헤드 · 다음 단어 예측 | **5-A 질문·이름표 매칭** · **5-B 어텐션 열지도/멀티헤드** · **5-C 다음 단어 맞히기** |
| 06 | LLM | 사전학습 → 지시 미세조정 → 사람 피드백 · 창발 · **미세조정과 LoRA** | LoRA 개념도 |
| 07 | LLM의 한계 | 환각·지식 시점·맥락 창·편향·비용, 각 한계의 원인과 보완 방법 | — |

## 파일 구조

```
index.html             강의 본문(한국어) · 섹션 마크업
css/style.css          디자인 시스템 (다크 "심야의 연구실" 테마)
js/hero.js             히어로 배경(뉴런 성좌) 애니메이션
js/main.js             내비 하이라이트 · 스크롤 진행바 · 등장 애니메이션
js/setmap.js           챕터 01 — AI/ML/딥러닝/트랜스포머/LLM 집합 지도
js/demos/neuron.js     데모 02 — 퍼셉트론 (AND/OR/XOR)
js/demos/network.js    챕터 02·04 — 신경망 신호 흐름 캔버스
js/demos/gradient.js   데모 03 — 경사하강 선형회귀
js/demos/rl.js         데모 04 — 그리드월드 Q-러닝 (Q-테이블)
js/demos/dqn.js        데모 04-보너스 — 같은 미로를 작은 신경망으로
js/demos/qkv.js        데모 05-A — Query·Key 매칭으로 주목도 계산
js/demos/attention.js  데모 05-B — 어텐션 열지도 · 멀티헤드
js/demos/nexttoken.js  데모 05-C — 다음 단어 예측
```

## 참고

- 헤드라인/본문 웹폰트(Gowun Batang, IBM Plex Sans KR 등)는 Google Fonts CDN에서 불러옵니다.
  인터넷이 없는 환경에서는 시스템 폰트로 자연스럽게 대체됩니다.
- 데모의 어텐션 행렬·Q/K 벡터·다음 단어 확률은 개념 전달을 위해 **직접 설계한 예시**입니다
  (실제 모델을 구동하지 않습니다). 학습 원리 자체(퍼셉트론·경사하강·Q-러닝·소형 MLP 역전파)는 실제로 동작합니다.
- 데모 04-보너스의 신경망은 각 칸의 정답 방향을 가치반복으로 미리 구해 놓고 **지도학습**으로 배웁니다.
  보상만으로 목표를 스스로 만드는 진짜 심층 강화학습과 다르다는 점을 본문에도 명시했습니다.
