# 인공지능은 어떻게 배우는가

비전공자를 위한 인터랙티브 AI 강의 사이트. 시냅스 하나의 학습에서 시작해
트랜스포머와 LLM까지, **직접 만져보며** 이해하도록 만든 단일 페이지 강의입니다.

## 실행 방법

빌드 도구·설치 없이 순수 HTML/CSS/JS로 되어 있습니다. 로컬 서버로 열기만 하면 됩니다.

```bash
# 프로젝트 폴더에서
python3 -m http.server 8777
# 브라우저에서 http://127.0.0.1:8777 접속
```

> `index.html`을 파일로 직접 열어도 대부분 동작하지만, 일부 브라우저의 보안 정책 때문에
> 위처럼 로컬 서버로 여는 것을 권장합니다.

## 강의 구성

| # | 챕터 | 핵심 개념 | 인터랙티브 데모 |
|---|------|-----------|------------------|
| 01 | AI란 무엇인가 | 규칙을 짜는 대신 스스로 찾게 하기 | — |
| 02 | 학습이란 무엇인가 | 시냅스=가중치를 조정하는 것 | **뉴런 한 개의 학습** (퍼셉트론 AND/OR) |
| 03 | 기계학습 | 오차를 줄이는 방향으로 한 걸음씩 | **경사하강 선형회귀** (직선 드래그·자동 학습) |
| 04 | 강화학습 | 보상을 좇는 시행착오 | **그리드월드 Q-러닝** (미로 탐색 에이전트) |
| 05 | 트랜스포머 | 단어들이 서로 주목(attention) | **어텐션 열지도** + **다음 단어 예측** |
| 06 | LLM | 위 조각들의 거대한 합 | — |

## 파일 구조

```
index.html            강의 본문(한국어) · 섹션 마크업
css/style.css         디자인 시스템 (다크 "심야의 연구실" 테마)
js/hero.js            히어로 배경(뉴런 성좌) 애니메이션
js/main.js            내비 하이라이트 · 스크롤 진행바 · 등장 애니메이션
js/demos/neuron.js    데모 02 — 퍼셉트론
js/demos/gradient.js  데모 03 — 경사하강
js/demos/rl.js        데모 04 — 강화학습
js/demos/attention.js 데모 05-A — 어텐션
js/demos/nexttoken.js 데모 05-B — 다음 단어 예측
```

## 참고

- 헤드라인/본문 웹폰트(Gowun Batang, IBM Plex Sans KR 등)는 Google Fonts CDN에서 불러옵니다.
  인터넷이 없는 환경에서는 시스템 폰트로 자연스럽게 대체됩니다.
- 데모의 어텐션 행렬·다음 단어 확률은 개념 전달을 위해 **직접 설계한 예시**입니다
  (실제 모델을 구동하지 않습니다). 학습 원리 자체(퍼셉트론·경사하강·Q-러닝)는 실제로 동작합니다.
